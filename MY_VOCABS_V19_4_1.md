# My Vocabs V19.4.1 — Bulk Status Auto Hide

Small reliability patch for V19.4.

- Successful bulk translation clears its saved queue and hides the progress strip automatically.
- Clicking Cancel also dismisses the progress strip immediately; unfinished words remain in the sheet and can be translated later with Translate All Missing.
- If translation completes with failed/untranslated rows, the strip stays visible only so Retry Failed remains available.
- Pause/Cancel controls are not shown for a terminal job.
- No dialogue, vocabulary, phrase, account, scoring, or learner-progress schema changes.
