# My Vocabs V19.5

V19.5 keeps the V19.4.2 spreadsheet workflow and removes the visible Actions column.

Visible columns:

`No. | English | Hindi Meaning | My Synonyms | Recall`

Right-click a row to Play, Translate/refresh Hindi, change Recall status, or Delete. If multiple rows are selected, the menu applies to the selection. Normal selected text inside an editor keeps the browser's native context menu.

Existing behavior is preserved: frozen No./English/Hindi columns, sticky table header, resizable/autofit widths, Compact/Comfortable density, English-only CSV import, paced online bulk translation, Enter-to-next-English-row, and Shift+Arrow row selection.

My Vocabs persistence is also optimized: rapid/bulk changes update the in-memory sheet immediately and disk persistence is coalesced. The store is flushed before unload/when hidden and before cloud synchronization.
