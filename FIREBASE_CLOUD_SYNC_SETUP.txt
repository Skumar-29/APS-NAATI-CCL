APS NAATI CCL PRACTICE - FIREBASE CLOUD SYNC v11
==================================================

LEARNERS NEVER CONFIGURE FIREBASE.
The Firebase Web configuration is embedded in the GitHub build.
A new learner or a learner on a new device only creates/signs into an account.

ONE-TIME PROJECT SETUP FOR THE APP OWNER
----------------------------------------
1. Firebase project: aps-naati-ccl-practice
2. Authentication: Google and Email/Password enabled.
3. Authentication > Settings > Authorized domains: include the GitHub Pages hostname.
4. Firestore Database exists.
5. Recommended Firestore Rules:

rules_version = '2';

service cloud.firestore {
  match /databases/{database}/documents {
    match /apsUserProgress/{userId} {
      allow read, write: if request.auth != null
                         && request.auth.uid == userId
                         && (request.auth.token.email_verified == true
                             || request.auth.token.firebase.sign_in_provider != 'password');
    }
  }
}

ACCOUNT EXPERIENCE
------------------
Google:
- Sign in/create account through Google.
- No additional email-verification screen is required for trusted Google accounts.
- Cloud sync starts automatically.

Email/Password:
- Create account with email, password and password confirmation.
- Firebase sends a verification EMAIL LINK (not a numeric email code).
- Cloud sync remains locked until the email is verified.
- Resend verification and I have verified controls are built into the app.
- Forgot password and Reset password send Firebase password-reset emails.

NEW DEVICE
